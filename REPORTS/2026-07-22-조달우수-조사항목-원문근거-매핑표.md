# 조사항목-원문근거-매핑표

본 문서는 조달청 우수조달물품 지정제도에 대한 조사 항목(RQ)과 원문 근거(Claim) 간의 매핑을 제공합니다.

| RQ | 매핑 Claim ID | 비고 |
|----|----|----|
| RQ-0~1 (정의/경계) | C01 | S01~S03 대조 예정 |
| RQ-2 (신청자격) | C02, C03 | 결격, 제조등록 |
| RQ-3 (대상품목) | C07 | 중복, 제외제품 |
| RQ-4 (필수/선택 요건) | C04, C05, C06 | 기술, 품질, 법정인증 |
| RQ-5 (신청서류) | C08 | 발급기한 등 |
| RQ-6 (심사/지정) | C09, C10 | 처리기간, 1차/2차 |
| RQ-7 (일정/비용) | C11, C12 | 접수회차, 수수료 확인필요 |
| RQ-8 (지정 후 의무) | C14 | 변경통보 등 |
| RQ-9 (갱신/연장) | C13 | 유효기간, 연장기준 |
| RQ-10 (탈락/제재) | C15 | 탈락, 취소사유 |

> **Evidence Tier 1 (파일):** 파일 생성됨. 원문 대조 및 HTTP fetch는 본 세션에서 차단되어 **unverified**. C12, 로그인 UI, 품목별 강제인증은 추가 확인 필요(미확인).
