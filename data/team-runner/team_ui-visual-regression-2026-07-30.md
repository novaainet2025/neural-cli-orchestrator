## 3) 다음에 필요한 작업 제안

다음 수집이 있어야 T1 근거로 판정 가능하다.

### A. 스크린샷 수집 (필수)

1. **대상 URL/화면** 명시 (예: 대시보드 팀 목록, 회사명 헤더 — **미확인**, 담당팀이 지정 필요)
2. **뷰포트**
   - 데스크톱: 예) 1920×1080 (**미확인**, 팀 표준 필요)
   - 모바일: 예) 390×844 (**미확인**, 팀 표준 필요)
3. **캡처 항목:** 회사명·팀명이 보이는 DOM 영역 전체 + 주변 레이아웃
4. **산출물:** PNG/WebP, 파일명에 날짜·뷰포트·화면 ID 포함

### B. 회귀 비교 (필수)

1. **baseline** 날짜/커밋/빌드 ID 지정 (**현재 미확인**)
2. pixel diff 또는 시각 diff 도구 결과 (diff 이미지 + 임계값)
3. 한글 관련 회귀는 **글리프 잘림·줄바꿈·`text-overflow`** 별도 체크리스트

### C. 반응형·접근성 체크리스트

| 체크 | 수집 방법 |
|------|-----------|
| `overflow: hidden`으로 인한 잘림 | 요소 bounding box + computed style 캡처 |
| flex/grid 겹침 | z-index, overlap bbox |
| 대비 | WCAG 기준 대비비 수치 (최소 4.5:1 본문) |
| 긴 한글 팀명 | 최대 길이 샘플 3종 이상 |

### D. 운영 정합 (권장)

1. 대기 1건이 시각 검사 태스크인지 **태스크 ID·제목** 확인
2. `claude-code` idle vs working 불일치 원인 조회
3. 캡처 자동화 실패 시 `claude-code` 24시간 실패 59건과 연관 로그 교차 (**인과 미확인**, 로그 필요)

### E. 판정 게이트 (수집 후)

- **PASS:** 데스크톱·모바일 모두 한글 회사·팀명 잘림/겹침/오버플로 없음 + 대비 기준 충족 + baseline 대비 회귀 없음 (T1 스크린샷·diff)
- **FAIL:** 위 항목 중 1개라도 재현 (증거 첨부)
- **BLOCKED:** URL·baseline·뷰포트 표준·캡처 권한 중 하나라도 미정
